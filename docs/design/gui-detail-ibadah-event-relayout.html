2Tetap sama (alur & informasi)

  • Semua data yang sekarang tampil tetap ada — hanya dipindah ke ringkasan, baris yang bisa dibuka, atau tab.
  • Geser check-in, Batalkan, kode jemput CKids, popup rincian peserta, bayar/unggah bukti, isi formulir: tidak berubah.
  • Bilah bawah (hitung mundur, QR, Reservasi / Self check-in / Daftar) tidak berubah.
  • Data dari server sama; tidak ada perubahan API → aman untuk 2.5.1, app 2.5.0 tidak terdampak.

3Perlu keputusan Anda

  • Tiket keluarga: carousel geser (usulan) atau tetap bertumpuk tapi versi ringkas?
  • Gambar event: dibatasi tinggi + latar blur (gambar tetap utuh) — setuju? Sebelumnya diputuskan “rasio asli, tidak terpotong”.
  • Tab vs bagian yang bisa dibuka-tutup (accordion) untuk Deskripsi / Formulir / Tim?
  • Syarat & Pembayaran: tertutup bawaan, kecuali syarat belum dipenuhi → otomatis terbuka?
  • Video teaser: tetap membuka link di luar (seperti sekarang), atau bila link YouTube diputar di dalam app memakai pemutar Video Channel?
